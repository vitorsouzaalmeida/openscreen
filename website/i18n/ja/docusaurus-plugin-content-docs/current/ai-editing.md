# AI 編集

OpenScreen は独自のモデルを持たず、アプリに接続するモデルもありません。AI 編集は、Claude Code や Codex など、すでに使っているエージェントが行います。エージェントは OpenScreen の MCP サーバーである `openscreen mcp` を起動し、そのツールを通して作業します。エージェントは自身のアカウントでサインインし、OpenScreen がそれを目にすることはありません。OpenScreen 自身は、どのモデルにも何も送信しません。エージェントがツールを通して読み取るもの（プロジェクト、文字起こし、静止フレームなど）は、そのエージェントのプロバイダーに、あなたがそこで持つアカウントのもとで送られます。アプリ自身のネットワーク利用（文字起こしモデルのダウンロード、アップデートの確認）は、[FAQ](./faq.md#does-openscreen-work-offline)に記載しています。

:::tip
どれも必須ではありません。録画、編集、文字起こし、字幕、エクスポートはすべて、アカウントもエージェントもなしで動作します。このうちダウンロードが必要なのは文字起こしだけで、初回実行時に[文字起こしのモデル](./captions.md#transcribing)を一度だけ取得します。
:::

:::note
以前のバージョンには、自分の API キーでモデルのプロバイダーに接続する、エディター内のチャットパネルと、アプリの設定でオンにする MCP サーバーがありました。どちらも削除され、そのキーで動いていた 2 つの機能、字幕パネルの**翻訳**ボタンと、タイムラインの**自動強化**メニューにあった**スマートカット**も、あわせて削除されました。これらの作業は、ここで説明するツールを通して、あなた自身のエージェントが行います。
:::

## セットアップ {#setting-it-up}

アプリ側でオンにするものは何もありません。ポートも、トークンも、設定も不要です。エージェントは、`openscreen record` を実行するときと同じように、あなたの権限でアプリ自身の実行ファイルを `mcp` 付きで起動し、stdin と stdout でやり取りします。そのため、アプリ側で何も許可しなくても、画面を録画し、編集し、エクスポートできます。いちばん手早いのは、次の内容をAI エージェント（Claude Code、Codex、Cursor など）に貼り付けることです。

```text
Install the OpenScreen skills with `npx skills add getopenscreen/openscreen -y`, then follow openscreen-demo to make a demo video of this feature.
```

これらのスキルは、OpenScreen がなければ、同意を得たうえでインストールします。下のプラグインを使わずにこの方法でインストールした場合、`openscreen-demo` スキルが OpenScreen の MCP サーバーを追加し、続いて、新しいセッションを開いて *continue the OpenScreen demo* と伝えるよう求めます。エージェントが新しいツールを得られるのは、新しいセッションの中だけです。代わりに手動で設定するには、次のようにします。

```bash
claude mcp add openscreen -- "<executable>" mcp
codex mcp add openscreen -- "<executable>" mcp
```

`<executable>` はアプリの実行ファイルです。各システムでのパスは [CLI の実行](./cli.md#running-the-cli)に記載しています。Cursor などほかのクライアントでは、実行ファイルを `command`、`["mcp"]` を `args` とした stdio サーバーとして追加します。

これらのスキルは、リポジトリ自身のマーケットプレイスからプラグインとしても入手できます。Claude Code では次のとおりです。

```text
/plugin marketplace add getopenscreen/openscreen
/plugin install openscreen@openscreen
```

プラグインには OpenScreen の MCP サーバーが含まれています。小さな Node スクリプトがインストール済みのアプリを見つけて `mcp` 付きで起動するため、`claude mcp add` なしで、`/reload-plugins` のあとや新しいセッションでツールが使えます。使えるアプリが見つからない場合は、`openscreenSetup` というツールを 1 つだけ提供し、何を確認したかと OpenScreen の準備方法を伝えます。

プラグインを共有する Codex と ChatGPT デスクトップアプリでは、次のとおりです。

```bash
codex plugin marketplace add getopenscreen/openscreen
codex plugin add openscreen@openscreen
```

これで、アプリのインストール済みプラグインに OpenScreen がそのスキルとともに表示されます。こちらでは、MCP サーバーは上の `codex mcp add` コマンドで追加します。

## エージェントにできること {#what-the-agent-can-do}

行いたい編集を、普段の言葉で伝えます（「イントロの無音部分をカットして」「ターミナルを開いたところでズームして」など）。エージェントは再レンダリングではなく、実際のタイムライン操作で作業します。トリム、ズーム、再生速度の範囲、注釈（テキスト、矢印、画面上の個人情報を隠すぼかし）、取り込んだオーディオトラックとそのフェード、フルスクリーンカメラのセグメントの追加と調整、クリック位置への自動ズームの追加、クリップのイン点とアウト点やクロップの編集、別のソースの映像の配置、クリップの複製・並べ替え・削除ができ、文字起こしを読んで、あなたが指している箇所を見つけます。背景、余白、角の丸み、影、デバイスフレーム、フォーマット、カメラのレイアウト、カーソル、全体の音量といった動画の見た目も設定できます。さらに、設定にない視覚エフェクトを書くこともできます。[カスタムエフェクト](./effects.md)を参照してください。

とくに頼める作業が 2 つあります。

- **無音やフィラーワードのカット。** エージェントは文字起こしを読み、該当する区間をトリムとしてカットします。このトリムは、自分で作ったものと同じようにドラッグしたり削除したりできます。手作業の場合は、[文字起こし](./captions.md#transcript-editing)で 1 つずつカットします。
- **字幕の翻訳。** エディターに翻訳ボタンはありません。エージェントが字幕のフレーズを読み、自分のモデルで翻訳し、結果を文字起こしの横に言語レイヤーとして保存します。[翻訳](./captions.md#translation)を参照してください。[字幕](./captions.md)をオンにし、スタイルと位置を設定することもできます。

`transcribe` は、エディターがプロジェクトを開くときと同じように、プロジェクトのメディアに対して端末上の Whisper を実行します。

エージェントはすべてのプロジェクトを一覧でき、どれでも読み取りや編集ができます。OpenScreen が開いている間は、エージェントが別のプロジェクトを指定しない限り、ツールはエディターで開いているプロジェクトに作用します。プロジェクトの作成（空のもの、または動画ファイルから）、名前の変更、プロジェクトのメディアへの動画・音声・画像ファイルの追加や削除もできます。画像は、その画像を映す数秒の無音クリップとして追加されます。プロジェクトの削除はツールにありません。それはアプリであなたが行います。

## ライブ編集と取り消し {#live-edits-and-undo}

各編集は、反映された時点で保存されます。

- **エディターで開いているプロジェクト**では、OpenScreen の起動中、エージェントはアプリを通して作業します。編集はすぐにエディターに反映され、1 つひとつが、自分の編集と同じく `Ctrl/Cmd + Z` 1 回分の操作になります。エージェントには一連の編集の前にチェックポイントを保存するよう指示されているため、プロジェクトを 1 回の操作で元の状態に戻すよう頼むことができ、その操作自体も `Ctrl/Cmd + Z` で取り消せます。アプリが応答しない場合、そのプロジェクトへの編集は拒否されます。エディターが自分のコピーで上書きしてしまうためです。
- **それ以外のプロジェクト**では、編集はそのファイルに保存され、`Ctrl/Cmd + Z` では元に戻せません。エージェントは最初の編集の前にそのプロジェクトのチェックポイントを保存する必要があり、そこへ戻すことが唯一の取り消し方法です。

チェックポイントはメモリーに保持されます。OpenScreen の起動中は OpenScreen を終了するまで、そうでなければエージェントのセッションが終わるまで有効です。保持されるのは直近 20 個のチェックポイントだけなので、古いものはそれより前に消えることがあります。

## エージェントに動画全体を作らせる {#letting-an-agent-make-the-whole-video}

エージェントは、録画からエクスポートまで、動画全体を自力で作れます。`openscreen mcp` では、編集ツールに加えて `listSources`、`startRecording`、`stopRecording`、`setPointerTrack`、`exportVideo`、`exportAudio`、`exportCaptions`、`getFrames`、`getContactSheet`、`getBeforeAfter`、`getAudioReport`、`createProject` を使えます。録画バーと同じく、テイクには Web カメラやシステム自身のカーソルも録画でき、エクスポートでは書き出しダイアログのオプションを使えます。MP4 なら画質とフレームレート、GIF ならフレームレート、サイズ、ループです。`exportAudio` は、プロジェクトの音声、またはインポートした 1 本のトラック（`importMedia` と `addAudio` で追加したナレーションなど）を、MP4 のミックスとまったく同じように WAV または M4A に書き出します。`exportCaptions` は、字幕を書き出した動画のタイミングに合わせて SRT または WebVTT の字幕ファイルに書き出します。

エージェントは自分の作業を確認することもできます。`getFrames` は、動画の指定した瞬間や、`startSec` から `endSec` までの区間を見せます。`region` を指定すると、画像のその部分だけを動画本来の解像度で返すので、小さな文字も読めます。`getContactSheet` は、多くの瞬間をそれぞれの時刻付きで 1 枚の画像に並べます。動画全体のリズムや、ズームをフレームごとに確認するのに使います。`getBeforeAfter` は、一連の編集の前と後の同じ瞬間を並べて見せ、画像のどこが変わったかを示します。`getAudioReport` は、プロジェクトの音声のラウドネス、トゥルーピーク、無音区間を測定します。編集ツールのうち `listStylePresets` と `applyStylePreset` は、**プリセット**のいずれかの見た目を 1 回の編集でプロジェクトに適用します。

- **テイクはそれぞれ新しいプロジェクトになり**、プロジェクト一覧に表示されます。アプリで作った録画と同じく、記録されたクリックにズームが付きます。時間的にも画面上でも近いクリックは1つのズームにまとめられ、最初の数秒と最後は画面全体のままです。エージェントによる編集はすべてプロジェクトのファイルに保存され、元に戻すにはエージェントが作成するチェックポイントを使います。[ライブ編集と取り消し](#live-edits-and-undo)を参照してください。
- **テイクには、エージェントが求めるまで文字起こしがありません。** エージェントは、単語をカットしたり字幕をオンにしたりする前に `transcribe` を呼び出します。Whisper はあなたのマシン上で実行され、OpenScreen が開いていれば OpenScreen の中で実行されます。
- **スクリプトで操作するテイク**（たとえば Playwright）では、画面のポインターはまったく動きません。エージェントが `setPointerTrack` で自分の操作ログを OpenScreen に渡せば、動画には同じようにカーソルとそのズームが付きます。
- **スキル**は、作業のやり方をエージェントに教えます。`openscreen-demo` は、絵コンテから完成した動画まで作業を進め、そのあと、レビュアーがその場で変更を確認できるよう動画をプルリクエストに添付するか、X への投稿を下書きします。投稿は、あなたが了承してはじめて公開されます。ほかの 6 つは、それぞれ 1 つの工程をさらに掘り下げます。`openscreen-capture`（ウィンドウを開かずに録画する Web ページを含む、きれいで再現できるテイク）、`openscreen-motion`（ズーム、注釈、テンポ）、`openscreen-effects`（カスタムエフェクト）、`openscreen-sound`（ナレーション、音楽、ラウドネス）、`openscreen-review`（動画を出す前の確認）、`openscreen-deliver`（形式、サイズ、動画の受け渡し）です。`npx skills add getopenscreen/openscreen` ですべて追加できます。スキルは [`plugin/skills/`](https://github.com/getopenscreen/openscreen/tree/main/plugin/skills) にあります。
